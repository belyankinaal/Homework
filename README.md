1. Авторизация пользователя в системе
2. Открытие проекта
3. Проверка общего количества заведенных задач
4. Просмотр задач
5. Заведение задач, дефектов

## Команды
Запуск тестов:
```sh
 mvn clean test 
```

Генерация отчета allure:
```sh
 mvn allure:report 
```

Генерация и открытие отчета allure:
```sh
 mvn allure:serve 
```
После просмотра отчета allure:
```sh
 mvn clean  
```

После просмотра отчета allure закрыть вкладку браузера с отчетом и нажать стоп

## Особенности отчета
```typescript
- Аннотации @Step,@Epic,@Feature,@Store для детализации отчета
- Скриншоты при падении тестов отображаются в отчете
- Сохранение html-кода страницы при падениях
```
