авторизацию, вход по токену на локалхосте.

## Технологии

- Maven — система управления зависимостями и сборки проекта
- Java 17 — версия языка и компилятора
- Rest Assured — библиотека для API-тестирования
- JUnit 5 — фреймворк для юнит-тестов
- Selenide — библиотека для UI-тестирования
- Lombok — генерация геттеров/сеттеров и других шаблонных конструкций
- AspectJ — для аспектно-ориентированного программирования (используется с Lombok/Allure)
- Allure — фреймворк для генерации отчётов по тестам
- Cucumber 7 — для BDD-тестов
- Logback — библиотека логирования
- Jackson — работа с JSON

## Тестовые сценарии

Рик и Морти

1. Поиск информации по Морти Смит и выбор последнего эпизода с появлением Морти
2. Получение из списка последнего эпизода последнего персонажа
3. Получение данных по местонахождению и расе полученного в предыдущем пункте персонажа
4. Проверка на совпадение местоположения персонажа той же расы, что и Морти

Локалхост

1. Регистрация на локалхост
2. Неуспешная авторизация по невалидному логину
3. Неуспешная авторизация по невалидному паролю
4. Успешная авторизация по валидному логину и паролю
5. Неуспешный вход по невалидному токену
6. Успешный вход по валидному токену

## Команды

Перед началом работы:

```sh
Запустить App в проекте ForIfellowSchAT и не отключаться
```

Перед запуском автотестов в терминале:

```sh
Запустить CucumberRunnerTest и не делать clean
```

Запуск тестов:

```sh
 mvn test 
```

Генерация отчета allure:

```sh
 mvn allure:report 
```

Генерация и открытие отчета allure:

```sh
 mvn allure:serve 
```

После просмотра отчета allure:

```sh
 mvn clean  
```

После просмотра отчета allure закрыть вкладку браузера с отчетом и нажать стоп
После окончания работы с проектом остановить проект ForIfellowSchAT
